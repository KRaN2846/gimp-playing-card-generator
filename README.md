Цей плагін має на завдання автоматизувати та уніфікувати створення скінів гральних карт за допомоги GIMP. Закладені оновні можливості: 
 - Створення карт однакового розміру, з однакомими параметрами.
 - Автоматичне позиціонування піктограм мастей на тілі карти.
 - Автоматичне позиціонування піктограм рангів на тілі карти.
